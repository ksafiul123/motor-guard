ESP32 Wiring Guide

Predictive Maintenance System — Real Hardware

Before you wire anything:
  • Power OFF / unplug ESP32 while wiring
  • Double-check every GND connection — floating ground = garbage readings
  • DS18B20 REQUIRES the 4.7kΩ pull-up resistor — it will not work without it
  • Use GPIO34 for ACS712 — it is ADC1 and input-only (safe for analog)
  • Never connect 5V to ESP32 GPIO pins — it runs on 3.3V logic

Pre-power checklist
  • MPU6050 VCC → 3.3V (not 5V)
  • MPU6050 SDA → GPIO21, SCL → GPIO22
  • MPU6050 AD0 → GND
  • DS18B20 DATA → GPIO4 with 4.7kΩ pull-up to 3.3V
  • ACS712 OUT → GPIO34 (ADC1 only)
  • ACS712 IP+ and IP− in series with motor wire
  • All GNDs connected to ESP32 GND (common ground)
  • 220Ω resistor on each LED before GPIO pin
  • Motor powered from external supply via L298N
  • WiFi SSID and password updated in main.ino
  • SERVER_URL in main.ino updated with your PC's local IP
